Om Css

CSS (Cascading Style Sheets) är ett språk som används för att beskriva utseendet och formateringen av dokument skrivna i HTML.

Olika typer av CSS

  • Inline CSS: Stilar som appliceras direkt på HTML-element med hjälp av "style"-attributet.
  • Internal CSS: Stilar som definieras inom en "style"-tagg i dokumentets "head".
  • External CSS: Stilar som definieras i en separat CSS-fil och länkas till HTML-dokumentet.
